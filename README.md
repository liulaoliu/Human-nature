# D老师帮你办 · 英语精读、背词与产出训练

> 原名「学吧老哥」。数据目录、`xueba.db`、`XUEBA_*` 环境变量和备份文件名保持不变，避免老数据断档。

把一篇英文文章变成能**逐句读懂、划词积累、反复复习、开口仿写**的学习材料。

这是一个**本地优先**的英语学习工具：词库、文章、学习记录都留在你自己的电脑上；核心学习功能不需要账号，除了在线朗读之外也不依赖网络。AI 是加速器，不是前提——不配置 API key 也能用「复制提示词 → 网页 AI → 贴回结果」的方式完成翻译、语言点、出题和批改。

---

## 能做什么

| 模块 | 一句话说明 |
|---|---|
| 📖 **精读** | 粘贴或导入文章，自动切句；划词加入生词，逐句看翻译、语言点和语法 |
| ⚡ **速读** | 一次一句，先自己读再揭示；遇到已收藏的词，鼠标悬停就能看含义 |
| 📚 **生词本** | 按原形去重，自动记录来源文章和原句；支持筛选、分组、打印和导出 |
| 🧩 **语言点** | AI 总结的词组、习语、搭配和用法自动收进词库，可筛选、可练习、可打印 |
| 🧠 **背单词** | 间隔复习；学新词、复习、拼写测试、错题重练，一条完整链路 |
| 📝 **考试** | 拼写、看词选义、词形辨析、搭配、介词、习语、语法标记、句子排序、中译英等 |
| 🎧 **听写与听力** | 逐句听写（词级纠错）、听音填空、听力理解、阅读理解 |
| ✍️ **仿写与回译** | 仿写范句并由 AI 批改；看中文写英文，再和原句逐词对照 |
| 🏫 **D老师小课堂** | 从文章里挑金句，按「遣词造句 → 逆向回顾 → 仿写考试」把句型真正用出来 |
| 🐄 **D老师奶牛工棚** | 全脂随机主题（可带本机词块）/ 脱脂奶按主题（可带本机词块）/ 风味酸奶逐句中英翻译 |
| 🗣 **朗读与跟读** | 任意文章都能朗读；可选跟读练习，支持录音、A/B 对比和手动切块 |
| 📅 **计划与记录** | 今日计划、学习日志、目标备忘、统计看板、连续学习天数 |
| 💾 **数据与备份** | 一键导出全部数据；支持合并导入、文章包、学习记录快照 |

## 一条推荐学习路线

1. **导入一篇**感兴趣、长度约 300–800 词的英文文章。
2. **精读一遍**：切句、划生词、补翻译和语言点，先求看懂。
3. **速读一遍**：遮住解释逐句自测，把没吃透的句子标出来。
4. **背今天的词**：清掉到期复习，再学一小批新词。
5. **挑 3–5 个金句**：进 D老师小课堂做填空、拼句和逆向回顾。
6. **仿写一两句**：让 AI 批改，把「认识」变成「会用」。
7. **去奶牛工棚写几句**：全脂随机主题 / 脱脂奶按主题（都可选带本机词块）/ 风味酸奶粘中英对照逐句翻译；批改后必须重写一版。
8. **第二天回来复习**：错题、错因和到期单词会自己排到前面。

> 建议少量精读、反复消化。读三篇走马观花，不如把一篇读透。

## 功能细节

### 📖 精读

- 支持粘贴正文，或导入 `.txt` / `.md` / `.pdf` / `.epub`；PDF 可指定页码范围，EPUB 按章拆成多篇。
- 自动清洗 PDF 常见伪影并切句；正文和 AI 结果一起保存，刷新或下次打开会回到上次那篇。
- 单击选句、拖动按整词选、`Ctrl` 点选单个词；选中后可加入生词、查词、翻译、看语法和搭配。
- 字号、加粗、衬线字体、护眼模式都可以按自己的习惯调。
- 滚动位置按文章记住；换字号或重新打开后仍能回到大致位置。

### ⚡ 速读

- 一次只显示一句，先自己读，再按空格揭示释义、语言点和翻译。
- 按 `R` 朗读当前句；已经收藏的词，鼠标悬停即可看含义，不用退出速读去查。
- 读完最后一句会自动记为「今天读完这篇」，计入目标和学习日志。

### 📚 生词本与语言点

- 生词按原形（lemma）去重：`running` / `runs` / `ran` 归到同一条，但每篇文章各自记录「本篇收了哪些词」。
- 每条词会保留来源文章和原句，避免离开语境背孤立的单词。
- 复习时按「认识 / 模糊 / 忘记了」三档评分；答错的词会自动进错题本，并在次日优先出现。
- 语言点（词组、习语、搭配、用法笔记）会自动收藏，和生词共用词库，但不会混进背单词和拼写题。
- 「生词浏览」页支持跨文章查看，按类型、关键词、加入日期、复习状态筛选，并批量导出或打印。

### 🔎 离线词典与例句

- 可选接入 ECDICT 和 M-W 学习者词典：查词、校正原形、补音标和词性、看真实 IPA 和英文释义。
- 可以按词汇量挑出文章里的超纲词，也可以给生词自动生成形近、义近的混淆选项。
- 支持离线 Tatoeba 例句：每个词可以补几条真实语境例句，和 AI 例句并存。
- 这些数据体积较大、各有许可，不随仓库分发；需要时在本机生成一次，之后全库通用。

### 🧠 背单词

- 分开处理「新词学习」和「到期复习」，不会把没学过的词直接塞进复习队列。
- 学习新词时先看词义，再选中文释义；第一次选对只算「模糊」，防止蒙对。
- 复习时可以直接判断「认识 / 模糊 / 忘记了」，忘记的词会重新进入学习流程。
- 每组学完有一轮**组末拼写测试**，学了多少拼多少。
- 错题本支持「错题包围战」：把错题、优先重练和学不稳的词混编反复考，直到全对。
- 考试设置里可以开启「反复鞭打错题」，一轮没全对就自动重练错题。

### 📝 考试与专项练习

按生词出题：

- 拼写、听音拼词、看词选义、词形辨析
- 例句填空、搭配填空、搭配默写、介词填空、习语填空
- 英英释义（写单词 / 选单词）
- 语法标记（可数 / 不可数、及物 / 不及物、可分级 / 不可分级）

按文章出题：

- 英译中、中译英
- 功能词填空、句子排序、结构 / 语法
- 词组 / 习语填空
- 听力理解、阅读理解

考试和听写的进度都会保存，刷新页面不会从第一题重来。答错的词会同步影响复习排期和错题本。

### 🏫 D老师小课堂

把文章里的好句子挑出来，练到能自己写：

1. **梳理思路**：看本篇段落脉络，选出要练的金句。
2. **遣词造句**：预览整句 → 填空 → 拼句 → 本句小结 → 本句仿写。
3. **仿写考试**：完成一定数量的句子后解锁，用学过的句型写新句子，AI 批改。
4. **逆向回顾**：看中文提示默写整句，首答全对才算真正掌握。
5. **本课总结**：汇总句子、句型、词组和单词，可导出 Markdown。

还有两个长期入口：

- **全库金句本**：跨文章搜索、筛选、导出 Markdown / Anki。
- **错因复盘**：把批改里的问题按规则汇总，看常错点、趋势和推荐语言点，并进入错因复习队列。

### 🐄 D老师奶牛工棚

用已经学过的词 / 词组 / 习语做**主动产出**，不是再做一遍选择题。入口在顶栏 **D老师小课堂右边**：

- **全脂**：不用写主题；AI 随机定主题。打开「带本机词块」就按配置从本机词 / 词组 / 习语里抽目标块；关掉就是纯随机主题。
- **脱脂奶**：先写主题；默认纯主题出句。打开「带本机词块」后，就和全脂一样附带目标块、目标块硬校验和每轮配置。
- **风味酸奶**：把原文 + 参考译文粘进来，先拆句预览，再手动合并 / 拆开 / 调整顺序；支持中→英、英→中，最后可加整段连写。参考译文在批改前不显示。

共同流程：

1. 全脂 / 脱脂奶可选角度、语气、难度、题目数；带本机词块时再选题型（翻译 / 挖空 / 词序）、范围（本篇 / 全库 / 最近 / 薄弱 / 到期 / 用错过 / 匹配主题）、每题目标数、薄弱比例；风味酸奶不需要这些。
2. AI 出题时只给中文情境，不先给英文答案；纯主题 / 翻译模式不展示 model，只有挖空 / 词序题型才给提示。AI 输出不合格会自动重试一次。
3. 你先写英文（或中文）；带本机词块时先做目标块硬校验，词形漏判可手工纠正；其余按参考译文 / 评分标准由 AI 批改。
4. 必须按批改意见重写一版，默认才能进下一题；也可以「跳过这题」（会留一条跳过记录）或「暂停」保留整组草稿，刷新后回到工棚继续。
5. 每稿都写进学习历史（`writing_records.source = production`）；工棚内「历史」能按文章 / 模式 / 主题筛选、两稿对比、看命中趋势和高频错因，并导出 Markdown。
6. 目标块进度由历史 attempts 现算（到期 / 薄弱 / 最近 / 用错过），不额外维护一份会漂移的进度表。

没配 AI key 时，会复制出题 / 批改提示词，粘回 JSON 即可；不会丢你的草稿。

### ✍️ 仿写与回译

- **仿写**：从范句生成写作任务和评分标准，你写完后由 AI 逐条批改；可以写第二稿，专门检查上一轮的问题改了没有。
- **回译**：先只看中文，自己写英文；批改后再看原句和逐词差异。原句只是参考，不要求逐字一致，专有名词的小差异不会被重罚。
- 仿写、金句课考试和回译都会留下历史记录，可按篇或跨篇回看、打印。

### 🗣 朗读与跟读

**朗读**：

- 任意文章、任意句子都能读，不依赖随附音频。
- 默认使用在线神经音色，可切换美式、英式、澳式、印度等多种口音。
- 可安装离线神经音色；没有网络时还能退回系统语音或浏览器语音。
- 支持逐词高亮、点某个词从那里开始播、整篇预生成（生成一次后连播几乎零延迟）。

**跟读（可选）**：

- 自动按音量切块，标准音和你的录音可以 A/B 对比，回放响度会自动对齐。
- 长句切得不准时，可以手动撕开、合并，也可以直接选字定块。
- 录音按块保存，刷新不丢；每块只保留最新一条。
- 跟读需要「原文 + 配套音频」。内置的自动匹配主要按 The Economist 杂志 PDF 打磨，其他来源可以手动对齐。

### 📅 计划、日志与统计

- **今日计划**：每天五件事——精读、速读、背词、朗读/跟读、仿写，自动带进度提示。
- **目标备忘**：设置每天读几篇；记录今天读完的篇目，回看历史热力图和连续天数。
- **学习日志**：按天查看新增了哪些生词、背过哪些词、新增了哪些语言点、当天做了什么练习。
- **统计看板**：今日 / 本周 / 本月 / 累计的听说读写活动量、正确率、学习时长和热力图。
- **掌握度**：按单词、句子结构、听力等能力分别看熟练程度，并跳到对应的练习。
- 「一天」以**凌晨 4 点**为界：0:00–3:59 的学习算前一天，熬夜不会把连续记录切成两天。

### 💾 导入、导出与备份

- **导出**：Anki CSV、单词表 TXT、A4 打印、仿写批改 Markdown、全库金句 Markdown。
- **文章包**：把单篇或多篇的正文、AI 结果、生词、语言点和相关学习记录打包，换电脑后合并导入。
- **导出全部**：词库、文章、学习记录、目标、备忘一起打包成一个 JSON。
- **合并导入**：保留本机现有数据，把备份并进来；生词按原形去重，统计按天累加。
- **学习记录快照**：服务端自动保留最近 12 版，误操作后可以回滚。
- 侧栏会提醒你多久没有导出备份；长期只存在一块硬盘上不算备份。

## AI 怎么用（可选）

不配置任何 key 也能用：

- 在应用里点「复制提示词」，去 DeepSeek、ChatGPT 等网页版粘贴，再把回答贴回「应用结果」框。
- 「AI 工作包」会把当前所有待办打成一个 JSON，整包交给 AI，再把结果 JSON 导回，适合一次补几十个词。
- 结果会逐条应用并给出回执，失败的条目可以单独重试。

如果想省掉复制粘贴：

- 走本机 agent：`npm run ai:agent`（或双击 `跑AI结果.cmd`），使用本机已配置的模型。
- 接 OpenAI 兼容服务：把地址、模型和 key 写进本机的 `config.local.json`。

> **API key 只放在本机。** `config.local.json` 和 `.env` 已在 `.gitignore` 里，不会进仓库；也不要把 key 写进 `config.json`、源码、文档、截图或提交记录。仓库里没有任何真实密钥。怀疑泄露时，先去服务商后台吊销再换新的。

## 快速开始

需要 Node.js **23.6 或更新版本**。

```bash
npm install
npm run dev
```

然后打开 **http://localhost:5173/reader**。

- 想先体验跟读页，打开 http://localhost:5173/
- Windows 也可以双击 `dev.cmd` 启动。
- 不要直接双击 `dist/index.html`：麦克风、文章加载等功能需要 `http://localhost`。

想用生产构建（首屏更快，但没有热更新）：

```bash
npm run app
```

想让它后台常驻、开机自启：

```text
启动服务.cmd        # 后台启动并打开浏览器
停止服务.cmd        # 停止后台服务
安装开机自启.cmd    # 登录 Windows 后自动启动
卸载开机自启.cmd    # 取消开机自启
```

Linux 下对应的是同名 `.sh` 脚本。

### 第一次打开建议

1. 先点「＋ 新建文章」，粘贴一篇英文，或导入 PDF / EPUB / TXT。
2. 如果要用 AI，先看右栏「选词·分析」里的提示词入口；不配 key 也能走网页版。
3. 想用离线词典，需要在本机生成词典数据（数据较大且有各自许可，不随仓库分发）；不生成也能正常阅读和背词。
4. 想练跟读，需要自己准备原文和配套音频。

## 数据存在哪

- 词库、已保存文章和学习记录默认放在本机的 `data/xueba.db` 里。
- 本地服务没启动时，会自动改用浏览器自带的本地存储，刷新和重启都不会丢。
- 朗读音频缓存可以随时重新生成，不算用户数据。
- 学习数据默认只在本机。使用在线朗读或 AI 时，相关文本会发送给你选择的服务商。
- 换电脑时优先用「导出全部」；也可以停掉服务后直接拷贝 `data/xueba.db`。
- 浏览器打开 `http://localhost:5173/api/store/db` 可以下载一份整库快照。

## 关于内容与版权

- 仓库**不包含**杂志文章正文、音频、词典原始数据和第三方例句库；需要自己导入或在本机生成。
- 内置的 PDF 抽取流程主要针对 The Economist 杂志版式；其他 PDF 可以直接用应用里的导入功能试试，抽不出来就手动粘贴。
- Edge 在线朗读使用的是微软的外部服务，非官方接口，适合个人自用；商用请换有正式授权的语音服务。
- 代码以 MIT 许可开源；第三方依赖和词典数据遵循各自的许可。
